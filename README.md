# 1 This multi agent project retrieves academic papers from openalex, evaluates it and searches for gaps.

## 2 To run this project you will need:
  Python 3.15
  Account and api key on OpenAlex
  pyalex 0.21
  python-dotenv1.2.4 (to load the key on the .evn) ex: OPENALEX_API_KEY=your_key_goes_here
  ollama 0.6.3
  pydantic2.14.4
  Standard-library modules (json, os, re, collections, typing) handle file I/O, string processing and type hints.

# 3 To run it you can use a terminal and write: python name_of_the_file.py
  you will have to do it for every file

# 4 The code will give out a message in the lines of:
  "Guardados 20 registos em evaluated_dataset.json"
